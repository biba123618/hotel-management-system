# hotel-management-system

 📝 Description
A modern Hotel Management System built using React.js and Next.js, designed to streamline hotel operations such as booking, check-ins, billing, and room management. This project offers a responsive, interactive user interface with real-time database integration through Firebase.



 🌟 Features
- Customer check-in and check-out management  
- Real-time room availability and booking system  
- Invoice and billing functionality  
- Admin dashboard with user-friendly controls  
- Fully responsive UI using Bootstrap and SCSS  
- Firebase authentication and real-time database integration  



💻 Technologies Used
- Frontend Framework: Frontend:
HTML, CSS, Bootstrap,JavaScript (ES6),React.js,Next.js

-Backend / Database:
Firebase (Authentication, Firestore)




 🚀 Future Enhancements
- Role-based user system (Admin, Staff, Guest)  
- Integration with third-party payment gateways  
- Email and SMS notification system  
- Booking calendar with drag-and-drop functionality  
- Analytics dashboard (occupancy rates, revenue, etc.)  
- Mobile app integration (React Native or Flutter)



⚙️ Setup Instructions
1. Clone the Repository:
   bash
   git clone https://github.com/biba123618/hotel-management-system.git
   

2. Install Dependencies:
   bash
   cd hotel-management-system
   npm install
   

3. Configure Firebase:
   - Create a Firebase project at [https://console.firebase.google.com](https://console.firebase.google.com)
   - Enable Authentication and Firestore
   - Copy your Firebase config to a `.env.local` file:
     
     NEXT_PUBLIC_API_KEY=your_key
     NEXT_PUBLIC_AUTH_DOMAIN=your_project.firebaseapp.com
     NEXT_PUBLIC_PROJECT_ID=your_project_id
     NEXT_PUBLIC_STORAGE_BUCKET=your_bucket
     NEXT_PUBLIC_MESSAGING_SENDER_ID=your_sender_id
     NEXT_PUBLIC_APP_ID=your_app_id
     

4. Run Development Server:
   bash
   npm run dev
   

5. Visit in Browser:
   - Navigate to `http://localhost:3000` in your browser
